随听是一款支持自定义选歌规则的音乐播放器。导入本地音频，或同步网易云歌单，按范围、氛围、风格和语言生成下一批候选，再决定什么时候播放。

> 比如：从「我喜欢的音乐」里选 20 首安静、治愈的歌，近期收藏与老歌各占一半，避开最近在随听里听过的歌曲。

## 按自己的规则听

- **范围由你定**：从全部已导入曲库、指定歌单或收藏中挑选；不会自动扩大到平台全曲库。
- **想听与不想听都能选**：氛围、风格、语言可多选；「本次不听」用于排除候选，单曲／歌手黑名单可持续生效。
- **新收藏和老歌一起听**：调整最近加入歌单的歌曲占比，设置听过歌曲的冷却时间。分类不足或候选不够时会给出说明。
- **选下一批，不打断这一首**：生成只更新候选；明确点击「播放这批」才替换当前播放列表。底部播放器集中管理进度、列表、歌词和音质。
- **网易云按需连接**：同步歌单、查看日推、将候选另存为新歌单；红心先暂存本机，在「我的 → 喜欢同步」手动提交或只读核对。
- **自己的音乐留在本机**：支持普通音频、手工分类、标签、LRC / TXT 歌词和 JSON 资料备份；本地音频不上传、不转码、不修改原文件。

## 快速开始

### Android：安装后直接使用

从[原项目的 0.1.4 Release](https://github.com/ztcxry/suiting/releases/tag/v0.1.4-public) 下载 Android 预览 APK，支持 **Android 8.0+**，安装后不需要电脑服务常驻。

这是公开预览包。升级原作者的同签名公开预览版时可覆盖安装；请先备份资料，**不要先卸载**。自行构建的 APK 若签名不同，不能直接覆盖原包。构建和签名说明见[开发文档](docs/DEVELOPMENT.md)。

### 电脑：启动浏览器预览

准备 **Node.js 22+**；首次安装依赖需要联网。

```sh
git clone https://github.com/ztcxry/suiting.git
cd suiting
npm ci
npm start
```

看到「随听已启动」后打开 **<http://127.0.0.1:4392/>**，保持终端运行，按 `Ctrl+C` 停止服务。Windows 也可以在下载项目后双击 **`启动随听.cmd`**，自动安装依赖并打开浏览器。

已有项目时直接进入目录即可。端口占用时先关闭旧实例，或通过 `PORT` 环境变量指定其他端口；不要删除已有曲库或盲目升级依赖。

## 第一次听歌

首次进入会显示三步指南，关闭后可用顶部「指南」重新打开。

1. **带上你的歌**：点击「导入本地音乐」选择普通音频；或点击「连接网易云音乐」→「生成登录二维码」，用网易云 App 扫码，再读取歌单并点击「同步」。同一手机可保存二维码后从「扫一扫 → 相册」识别。
2. **选一种听法**：在工作台选择歌单、氛围和首数，点击「生成随机队列」。初次建议不限氛围、20 首；风格、语言和精细设置可以稍后再调。
3. **开始听**：查看「下一批候选」，点击「播放这批」；已有播放列表时点击「替换播放列表并播放」。想用网易云客户端听，可以选择「保存到网易云」并确认创建新歌单。

**扫码登录 ≠ 歌单已同步；同步歌单 ≠ 下载音频。** 登录后点击「读取我的歌单」，再选择需要同步的歌单。随听不会接管网易云客户端的登录状态和播放队列。

| 操作 | 作用 |
| --- | --- |
| 生成 / 换一批 | 更新候选，保留当前播放 |
| 播放这批 | 交接候选并开始播放 |
| 换顺序 / 清空候选 | 仅整理候选，不停止当前播放 |
| 收藏到随听 | 保存在本机收藏中 |
| 网易云红心 | 暂存账号对应的本机操作，手动同步后才写入平台 |

单曲／歌手黑名单会立即排除播放列表中的相关歌曲；「本次不听」只筛选候选，不追溯打断当前播放。歌手匹配依据平台 ID，缺少 ID 时按完整署名匹配。

## 常见问题

<details>
<summary>为什么筛选后歌很少？「近期」是最近发行的新歌吗？</summary>

分类来自文件信息、网易云百科辅助信息或手工标注，**没有 AI 听音分类**。「智能宽松」按设置补充相近或待分类歌曲；「严格」只选精确标签。可使用「补全分类」、减少条件或调整冷却时间，并展开「本批规则与匹配说明」核对。

「近期」主要指**最近加入歌单**的歌曲，默认参考 100 首。缺少添加时间时可按歌单顺序补足，页面会说明依据。冷却记录来自随听内播放和手动「标记听过」，不是网易云完整播放历史。

</details>

<details>
<summary>重启后要重新登录吗？如何备份和升级？</summary>

浏览器版登录态保留在本机服务内存中，服务重启后需重新扫码。曲库资料和导入音频副本保存在当前浏览器中；请固定使用同一浏览器和地址，`localhost` 与 `127.0.0.1` 的存储相互独立。

在「连接音乐 → 备份与本机资料」导出 JSON。它不包含音频、文件授权、账号凭据或待同步喜欢日志，请另外保管原始音频。Android 使用所选文件的只读授权，移动文件或撤权后需重新选择。

待同步喜欢日志按账号独立保存，覆盖升级保留；卸载或清除应用／站点数据会丢失，清理前请手动同步。平台不提供逐首喜欢时间，随听不能精确还原官方“今日新增”。

</details>

<details>
<summary>能播放会员歌曲或网易云下载的 NCM 文件吗？</summary>

本地支持 MP3、FLAC、M4A、AAC、WAV、OGG、OPUS 等普通音频，具体编码取决于设备。NCM / QMC 等加密文件不能直接播放。

网易云为非官方适配，播放取决于账号权限、会员、地区和版权，接口可能变化。随听不绕过付费、试播或 DRM 限制，也不提供加密音乐解锁。

</details>

## 预览版边界与隐私

网易云与搜索彩蛋默认关闭，可在「我的 → 功能插件与 DIY」管理。彩蛋使用原创动态唱片与小调；本地音乐和随机核心无需联网插件。项目无广告、分析统计或遥测，数据处理详见[隐私说明](PRIVACY.md)。

[0.1.4 更新记录](docs/CHANGELOG-0.1.4.md#验证边界)记载了 **256 项 JavaScript、71 项 JVM 测试**及优化 Android 构建通过。这是该版本的验证记录，不代表已完成实机或真实账号端到端验收。后台／锁屏播放、通知操作、悬浮歌词权限及文件跨重启授权仍需设备验证。

同一记录披露：Node 运行时依赖审计仍有 5 项高危告警，未宣称安全问题已清零。当前不支持 QQ 音乐、任意脚本安装或 AI 听音分析。
